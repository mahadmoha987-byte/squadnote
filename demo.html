Intended API use

Squadnote supports Competitive only. This demo runs in your browser using fictional data. The production integrations below are planned.

Riot Sign On (RSO)
Identifies the signed-in player and supports the account-linking and consent flow.
VAL-MATCH-V1
Verifies shared matches so feedback comes from teammates who played together.
VAL-CONTENT-V1
Supplies agent data for the production app. This demo uses a supplied screenshot as an illustration.
Overwolf game events
Provides the agent-select roster in the Windows overlay. The Riot API itself does not supply the live roster.

Player opt-in, visibility and community-feedback rules will follow Riot’s guidance before launch. No production approval is implied by this demo.
